# Dataset Overview

## Project
E-commerce Cohort & Retention Analysis

## Dataset Description

This dataset contains customer purchase transactions from an e-commerce platform.

## Important Columns

| Column | Description |
|---------|-------------|
| order_id | Unique order identifier |
| order_date | Purchase date |
| cust_id | Unique customer ID |
| price | Order price |
| qty_ordered | Quantity purchased |
| status | Order status |
| category | Product category |
| payment | Payment method |
| year | Purchase year |
| month | Purchase month |

## Purpose

The dataset will be used to perform:

- Cohort Analysis
- Customer Retention Analysis
- Customer Churn Analysis
- Customer Lifetime Value (CLTV)
- Power BI Dashboard
